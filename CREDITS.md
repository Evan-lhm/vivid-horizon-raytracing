# Credits

Vivid Horizon Vibrant is written for Horizon's shader API 0.2 (WGSL). It contains no code, textures or data from
Minecraft, Mojang or Microsoft. `blue.png` (blue-noise texture) is generated by the author (void-and-cluster), not downloaded.

Techniques studied and re-implemented in WGSL (no code copied verbatim; named in the source comments):
- **PTGI** (path-traced global illumination for Minecraft shaders, Unlicense / public domain): the bounce loop shape,
  the 60-frame history, and the edge-stopping a-trous spatial filter after SVGF.
- **SVGF** (Schied et al., "Spatiotemporal Variance-Guided Filtering"): edge-stopping filter idea.
- Standard atmospheric models: Rayleigh and Mie scattering, ozone absorption; Beer-Lambert absorption in water;
  Schlick's Fresnel approximation.
